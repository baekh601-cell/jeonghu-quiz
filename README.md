# ✈️ 정후의 비행 퀴즈

비행기 안(인터넷 없음)에서 오래 즐길 수 있는 오프라인 퀴즈 웹앱.

## 게임
- **지도에서 도시 찾기** — 세계 / 대한민국 지도에서 도시 위치를 콕 찍기. 가까울수록 고득점 (최대 1000점)
- **나라와 수도**, **국기** — 나라 데이터로 문제 자동 생성
- **역사**, **과학 상식**, **프로야구(KBO)**, **넌센스** — 문제은행
- **전부 섞기**, **오답 노트**, 레벨·기록

난이도(쉬움/보통/어려움/섞어서)를 고를 수 있고, 안 푼 문제부터 나온다. 기록은 기기에 저장된다.

## 오프라인으로 쓰는 법
1. 인터넷이 될 때 휴대폰/태블릿 브라우저로 앱 주소를 연다.
2. **홈 화면에 추가** (아이폰 Safari: 공유 → 홈 화면에 추가 / 안드로이드 Chrome: ⋮ → 홈 화면에 추가).
3. 홈 화면 아이콘으로 한 번 실행해 두면, 비행기 모드에서도 전부 동작한다.

## 개발
- 빌드 도구 없는 순수 HTML/CSS/JS. 로컬 실행: `npx http-server . -p 5173`
- 문제 추가: `data/*.js` 에 `{q, a, w:[오답 3개], d:1~3, e:'해설'}` 형식으로 추가
- 지도 데이터 재생성: `npm install && npm run build:map` (Natural Earth, 퍼블릭 도메인)
- 파일을 바꾸면 `sw.js` 의 `VERSION` 을 올려야 설치된 앱이 새 버전을 받는다.
